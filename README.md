
# 🔐 Image Encryption & Decryption Tool

A Python application that securely encrypts and decrypts images using XOR-based pixel manipulation.

This project demonstrates basic cryptography concepts and image processing using Python, Pillow, and NumPy.

## ✨ Features

- Encrypt images using XOR encryption
- Decrypt encrypted images using the same key
- User-defined encryption key
- Fast image processing
- Error handling

## 🛠 Technologies Used

- Python
- Pillow (PIL)
- NumPy

## 📂 Project Structure

```
main.py
requirements.txt
README.md
images/
```

## 🚀 Installation

```bash
git clone https://github.com/anshuman192/project_01.git
```
